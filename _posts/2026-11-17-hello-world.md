## How to write a new post

1. Add a file to the `_posts` folder named like `YYYY-MM-DD-my-post-title.md`.
2. Start it with a front matter block (`layout`, `title`, `date`) like this post.
3. Write the rest in Markdown, then commit and push. GitHub Pages rebuilds the site in a minute or two.
